# Curio-Bot
🤔 CURIO — The “Why Not?” Bot  CURIO is a curiosity-driven chatbot that answers questions by exploring alternatives, possibilities, and constraints. Ask “Why can’t…?” or “Why not…?” and CURIO breaks things down with clear explanations, examples, and smart follow-ups.  From science and tech to everyday curiosi CURIO helps you think beyond yes or no.
